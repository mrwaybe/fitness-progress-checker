# User Guide

### Accessing the Application
Connect your device directly to the Raspberry Pi via the link-local network configuration. Open your web browser and navigate to the Raspberry Pi's assigned static IP address.

### Calculating BMI and Logging Progress
1. On the main page (`index.php`), input your height and weight into the provided form fields.
2. Submit the form to calculate your Body Mass Index (BMI).
3. The system will display your current BMI category and automatically save this fitness record to the database.

### Viewing Progress History
1. Click the "View History" link to navigate to `history.php`.
2. This interface provides a chronological table of your past entries, allowing you to track how your weight and BMI have changed over the course of your fitness tracking.

### Viewing Team Introductions
To view information about the application developers, click the "Team Introductions" link on the main page. This will display the member biographies integrated from the earlier phase of the project.
